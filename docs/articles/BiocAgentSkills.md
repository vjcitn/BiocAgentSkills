# BiocAgentSkills package overview

<div class="section level2">

## Introduction

It is a premise of this package that R package discipline should be used
to manage documents that are intended to serve as “skills” for agentic
software engineering and analysis in the Bioconductor ecosystem.

</div>

<div class="section level2">

## Structure

`inst/demoskills` hold drafts of skills for automated evaluation in the
development of this package

`inst/evaluation_support` holds scripts and a README.md to describe how
an evaluation report is produced.

`inst/resources` is a folder tree with various skill documents and
documentation to support diverse agents and agentic processes.

Package vignettes provide more details on an approach to skill
evaluation.
